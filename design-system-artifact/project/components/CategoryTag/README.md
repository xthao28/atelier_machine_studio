A pill-shaped mono tag that names the topic of a post.

- Outline is the default. Use at most one filled tag per slide; fill by meaning: `lilac` concept, `lime` technical, `orange` artificial life or XUNA, `ink` hardware.
- Tags are the only pills in the system. Labels, IDs and panels stay square.
- Upper-case mono 500, 22 px, +.08em; padding 12 × 20; 3 px border.
