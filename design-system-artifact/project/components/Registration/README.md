Technical grid overlays, crosshair markers, coordinate labels and circular targeting elements.

- Each mark has a job: grids show the module, crosshairs mark corners and points, coordinates locate objects, targets isolate a subject.
- Draw in `rule` colour at `stroke-line` (3 px) or `stroke-hair` (2 px). One target per slide at most.
- Coordinates are mono, upper-case and invented only as sample data; never imply a real location of a private person.
