A two-part identifier: an inverted prefix block and a numbered cell, for experiments, logs and figures.

- Prefixes: `EXP` experiment, `LOG` build log, `FIG` figure. Numbers are zero-padded to three digits; sub-figures use a letter.
- One per slide, placed under the headline or on the image caption. Never combine two prefixes in one tag.
- Mono 500, 26 px. The block inverts with the surface, so it works on paper, ink and the accent fields.
