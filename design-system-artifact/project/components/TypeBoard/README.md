Every text style at the size it is used on a 1080 px canvas, with Vietnamese coverage.

- Space Grotesk carries headlines, titles and running text; IBM Plex Mono carries IDs, labels, metadata and coordinates.
- Both families cover Vietnamese; test every diacritic stack (ệ, ữ, ỳ) in headlines before publishing.
- Do not set paragraphs in mono and do not use decorative or futuristic fonts.
