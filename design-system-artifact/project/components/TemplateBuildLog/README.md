Document the process of making physical technology like a modern engineering journal.

- Cover: lime stage block (`label` + 200 px numeral) beside an `h1` title, `ExperimentId` and tag, then a real photograph in `ImageFrame` with numbered pins and a three-value `TechnicalLabel` row.
- Inner slides: Components (photo + four `NumberedStep`s), Firmware (code in `am-code`: `ink` ground, `lime` keywords, `orange` numbers; three steps), Progress (six stage rows with `StatusIndicator` and a `ProgressIndicator`).
- Photography is real bench work. Code snippets are real, compilable and at most 10 lines at 26 px mono.
- End with the next log's title as the call to action.
